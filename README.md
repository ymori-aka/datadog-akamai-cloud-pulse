# Datadog integration for Akamai Cloud Pulse (unofficial)

> **Unofficial.** This is a community project. It is not an official Datadog
> integration and is not supported by Akamai Technologies or Datadog, Inc.

A Datadog Agent check that collects metrics from
[Akamai Cloud Pulse](https://techdocs.akamai.com/cloud-computing/docs/akamai-cloud-pulse)
(the Akamai Cloud / Linode monitoring API) and submits them to Datadog.

The integration lives in [`akamai_cloud_pulse/`](akamai_cloud_pulse/) and follows the
[`DataDog/integrations-extras`](https://github.com/DataDog/integrations-extras) layout,
so it can be submitted upstream later without restructuring.

## Status

Work in progress. See [`akamai_cloud_pulse/README.md`](akamai_cloud_pulse/README.md).
